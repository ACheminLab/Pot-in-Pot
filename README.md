# Pot-in-Pot Evaporative Cooling interactive model

Open `index.html` locally or publish this folder with GitHub Pages. The simulation has no build step and no external dependencies.

The temperature obeys a lumped energy balance. Wind and relative humidity modify an adjustable evaporation-rate reference. Wet-surface mode holds evaporation constant; finite-film mode reduces the evaporation rate exponentially. The approximation does not resolve spatial gradients or temperature-dependent evaporation.

Reference: A. Chemin et al., *American Journal of Physics* 86, 206 (2018). https://doi.org/10.1119/1.5016041
